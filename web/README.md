# MD Path Lab

Act as a world-class Senior Product Designer and Frontend Engineer.

Your task is to design a premium healthcare diagnostics website inspired by Healthians (https://www.healthians.com/) but DO NOT copy their design. Use it only as a UX and layout reference.

The final result should feel like a ₹500+ crore healthcare brand with excellent trust, premium quality, modern UI, and conversion-focused UX.

## Design Goals

This website should immediately communicate:

- Trusted Healthcare Brand

- NABL Certified Labs

- Professional Medical Services

- Safe & Secure

- Fast Booking

- Premium Experience

- High Conversion

Users should feel they are visiting India's #1 diagnostic platform.

Create a clean, premium and modern interface.

Avoid:

- Generic Bootstrap look

- Template feeling

- Flat boring cards

- Large empty white spaces

- Cheap gradients

- Outdated UI

- Large clean sections

- Soft shadows

- Premium rounded cards

- Beautiful spacing

- Modern icons

- Trust-focused design

- Premium color balance
